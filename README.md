# Next.js Testing Playground

A minimal Next.js App Router project with a small interactive page for testing
local development and basic UI behavior.

## Requirements

- Node.js 20.9 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The page includes a counter
and a form that can be used to try basic interactions.

## Checks

```bash
npm run lint
npm run build
```

Edit `app/page.tsx` to change the page.
